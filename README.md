# InfoPet 🥚

A digital companion that grows as you do. InfoPet is a Tamagotchi-style pet game about AI and Media & Information Literacy (MIL) — raise a thoughtful, careful, curious mind by feeding your pet good information and completing daily quests.

🔗 **Play it here:** https://ethandavid31.github.io/InfoPet/

## Features
- 🥚 Hatch and raise your own InfoPet from an egg
- 🧠 Build up Trust, Curiosity, Critical Thinking, Empathy, and Wisdom
- ⭐ Daily quests to grow your pet
- 🏆 Badges, journal, and a status/profile/journey dashboard
- 📲 Installable as an app (PWA) — works offline

## Tech Stack
Plain HTML, CSS, and JavaScript 

## Install it
Open the live link above, then:
- **Phone:** share menu → "Add to Home Screen"
- **Desktop (Chrome/Edge):** click the install icon in the address bar
